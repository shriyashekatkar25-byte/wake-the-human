The decision

How many failed attempts before the agent pages on-call?

Customer problem

A data platform lead owns 12 workspaces of nightly jobs. Their scheduler already retries. The new agent now spots failures, finds the root cause and drafts a fix. If it pages on every finding, the on-call engineer mutes it in a week. If it pages too late, the CFO's revenue dashboard is stale by breakfast.

Pinned to: who hurts today

Proposed change

Ship a default paging rule: page a human after N consecutive failed attempts of the same job. Optionally add a fast lane: if the agent's diagnosis is deterministic (schema change, bad code push, revoked credential), page on the first failure, since retrying cannot fix it.

The math, from my Monte Carlo course

Inverse CDF: one uniform number, any shape you need

The idea in plain words

A CDF tells you "what share of outcomes are at or below x." Flip it around: pick a random share U between 0 and 1, then ask which x sits at that share. Values of x where the CDF climbs steeply get picked often, flat stretches get picked rarely, which is exactly the right shape.

X = F⁻¹(U), U ~ Uniform(0,1)

It needs only a seeded uniform generator, so the whole simulation replays exactly from one seed. That matters when a VP asks "show me that week again."

Gaps between incidents

If findings arrive at an average rate λ per minute, the waiting time is exponential: F(t) = 1 − e^(−λt). Solving for t:

gap = −ln(1 − U) / λ

Product example: with 12 workspaces at 0.35 findings a day, the on-call sees about 29 findings a week. Attempt runtimes use the same trick with mean 6 minutes, so time-to-page is a sum of N such draws plus backoff.

How long a flaky job stays broken

If each retry heals with chance p, the number of failures before the first success is geometric, with P(F ≥ k) = (1 − p)^k. Inverting gives a one-liner:

F = ⌊ ln(1 − U) / ln(1 − p) ⌋

A flaky job causes a false page exactly when F ≥ N, so the expected false pages per week are findings × (1 − q) × (1 − p)^N. The page shows this exact number beside the Monte Carlo estimate as a sanity check.

Why simulate if a formula exists?

Means have formulas. The questions a director asks do not: "how often is a week noisy," "what share of real breaks reach a human inside an hour," "how many of the false pages land at night." Those depend on whole distributions of sums and counts, and averaging thousands of simulated weeks answers them directly, with error shrinking like 1/√n.

How I'd run it on real data

Fit λ, p and runtimes from run history, then replay the policy

Table names are illustrative. The plan: estimate the three inputs from last quarter's job runs, then feed them to the same simulator and replay "would-have-paged" in shadow mode before changing anyone's pager.

-- 1. Failure streaks per job run chain (SQL)
WITH runs AS (
  SELECT workspace_id, job_id, run_start, result_state,
         SUM(CASE WHEN result_state = 'SUCCESS' THEN 1 ELSE 0 END)
           OVER (PARTITION BY job_id ORDER BY run_start
                 ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING) AS chain_id
  FROM ops_demo.job_runs
  WHERE run_start >= current_date() - INTERVAL 90 DAYS
)
SELECT workspace_id, job_id, chain_id,
       COUNT_IF(result_state <> 'SUCCESS') AS failures,
       MAX(result_state = 'SUCCESS')      AS healed,
       MIN(run_start)                      AS first_fail_at
FROM runs
GROUP BY ALL
HAVING failures > 0;
# 2. Fit inputs, then simulate (Python)
import numpy as np
s = spark.table("ops_demo.failure_chains").toPandas()

flaky = s[s.healed]                    # healed on retry
p_hat = 1 / (1 + (flaky.failures - 1).mean())  # geometric MLE
q_hat = 1 - s.healed.mean()            # share of real breaks
gaps = s.sort_values("first_fail_at") \
        .first_fail_at.diff().dt.total_seconds() / 60
lam_hat = 1 / gaps.mean()              # exponential MLE

rng = np.random.default_rng(1102)
def false_pages(N, weeks=2000):
    k = rng.poisson(lam_hat * 10080 * (1 - q_hat), weeks)
    u = rng.random(k.sum())
    F = np.floor(np.log1p(-u) / np.log1p(-p_hat))
    return (F >= N).sum() / weeks
print({N: false_pages(N) for N in range(1, 7)})
